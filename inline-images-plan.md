# 📝 Per-Image Quality Checklist

Before exporting any inline image, verify:

- [ ] Background `#FAFAF9` (matches site)
- [ ] Real content (no AI-generated text)
- [ ] Centered with generous padding
- [ ] Single screen for `<ImageWithCaption />`, two screens 
      for `<ImageGrid columns={2}>`
- [ ] No 3D phone tilt (flat front-facing)
- [ ] Subtle shadow only (4-6% opacity max)
- [ ] PNG @ 2x scale exported
- [ ] File size under 2MB (Next.js optimizes at runtime)
- [ ] Filename is `[project-slug]-[descriptive-name].png` 
      (lowercase, dashes, no apostrophes)

# 🔧 How to Add an Image (Workflow)

## Step 1: Design and export from Figma

Frame at recommended dimensions, background `#FAFAF9`, real screen 
centered, export PNG @ 2x.

## Step 2: Save to project

```bash
mv ~/Downloads/dayratna-circle-detail-ar.png public/work/
```

## Step 3: Edit the MDX file

Open `/content/case-studies/[project].mdx`, find the right 
`<ImageWithCaption />` or `<ImageGrid />` placeholder, add the 
`src` attribute:

```mdx
<!-- Before -->
<ImageWithCaption alt="..." caption="..." />

<!-- After -->
<ImageWithCaption 
  src="/work/dayratna-circle-detail-ar.png"
  alt="..." 
  caption="..." 
/>
```

## Step 4: Verify locally

```
npm run dev
```

Visit `localhost:3000/work/dayratna` → image should render in 
the right place.

## Step 5: Commit and push

```bash
git add public/work/dayratna-circle-detail-ar.png
git add content/case-studies/dayratna.mdx
git commit -m "Add Da'eratna circle detail image"
git push
```

Vercel will auto-deploy the new image to production.

# 💡 Tips for Efficient Image Production

## Batch Similar Images Together
Don't bounce between projects. Do all 3 Tier 1 images for 
Da'eratna in one session, then move to KemeClinic, then Got-AI.

## Reuse Frame Templates in Figma
Create one master frame at 1600×1200 and 1600×900 with the 
correct background, padding, and shadow settings. Duplicate 
it for each new image — saves setup time.

## Prepare All MDX Edits in Advance
Before exporting, decide exactly which `src` filename each 
image will have. Write down the list. This prevents 
back-and-forth when wiring up.

## Don't Over-Polish Tier 2 and 3
Tier 1 deserves polish. Tier 2 and 3 should be quick. If 
you find yourself spending an hour on a Tier 3 image, you're 
optimizing in the wrong place.
